
## Files available for full database

### PR2 18S reference database

We recommend that you use [flat files](https://github.com/pr2database/pr2database/releases/tag/v5.1.0.0) provided with each new PR2 version for analysis of metabarcoding data.

Each version has a 3 number code: version_x.y.z, e.g. 5.1.0

* [Information about format of files.](https://pr2-database.org/documentation/pr2-files/)

* [Link to previous releases](https://github.com/pr2database/pr2database/releases)
